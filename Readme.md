# Telecom Customer Churn Prediction using AI

## Project Overview
This project was completed as part of the IBM SkillsBuild Data Analytics with AI Academic Internship (BharatCares & AICTE). It demonstrates end-to-end data analytics and machine learning techniques to predict whether a telecom customer will churn based on their account and demographic data.

## Dataset Link
The dataset is publicly available via Kaggle and IBM repositories:
[Telco Customer Churn Dataset]

## Technologies Used
* Python 3.x
* Pandas & NumPy (Data Manipulation & Cleaning)
* Matplotlib & Seaborn (Data Visualization)
* Scikit-Learn (Machine Learning & AI Modeling)

## Setup and Run Instructions
1. Ensure Python is installed on your system.
2. Install the required dependencies using the terminal command:
   `pip install -r requirements.txt`
3. Open the file in Jupyter Notebook or Google Collab.
4. Run the cells sequentially to load the data, view the visualizations, and train the AI model.

## Key Insights
1. Contract Type Matters: Month-to-month users are the most likely to churn.
2. Loyalty Pays: Customers with higher tenure have significantly lower churn rates.
3. AI Accuracy: The mathematically balanced Random Forest Machine Learning model predicts churn with ~80% accuracy, allowing the business to proactively target at-risk customers with retention offers.
